# Haiko

Haiko - сайт/приложения для поиска, создания и пошагового прохождения статей.
[AI USAGE](https://github.com/Arfind2321/Haiko/blob/main/AI%20USAGE.md)

## Функции

* Создание, изменение и удаление статей ( личный кабинет )
* Аватарки
* Пошаговое выполнение статей ( без аккаунта и с аккаунтом )
* Лайк/Дизлайк для каждого шага + комментарии
* Офлайн режим и экспорт статей в PDF
* Умный поиск и каталог всех статей
* Форк инструкции
* Поддержка нескольких платформ: Web, Windows 10/11, Android, IOS*, MacOS*, Linux*

"*" - теоретически поддерживается, однако не тестировалось

## Запуск
