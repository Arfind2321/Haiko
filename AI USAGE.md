Этот проект не был свайбкоден и писался около 2 недель и около 60-80 часов суммарного времени. Мы не приветствуем использование искуственного интелекта в соревнованиях. Данный проект ( моя часть и большая часть сокомандника ) была написана без нейросети. Снизу показан более точный отчёт об использовании ИИ в данном проекте:

### Frontend
* Использование искуственного интелекта отсутствует, за исключением [небольшой функции](https://github.com/Arfind2321/Haiko/blob/main/src/app/lib/main.dart#L13C1-L14C50) ( Arfind2321 )

### Backend
* central ( основной сервер для обработки практически всего ) отсутствие использоания ии ( Arfind2321 )
* vectorize ( сервис поиска ) отсутствие использоания ии, за исключением докер файла. ( aleksandr1512 )
* nginx отсутствие использования ии ( Arfind2321 +  aleksandr1512 )
* pdf-generator написано преимущественно с помощью ии ( aleksandr1512 )
